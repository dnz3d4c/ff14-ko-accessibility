# patches — 업스트림에 올릴 변경

한국을 언급하지 않고도 성립하는 변경만 여기 둔다. **KR 전용은 `overlay/patches/`다.** 커밋 훅이 두 경로를 섞는 커밋을 거부한다([docs/commit-rules.md](../docs/commit-rules.md) §2.2).

## 여기 있어도 로컬에서 적용된다

이 디렉토리는 "나중에 보낼 것을 쌓아 두는 곳"이 아니다. **먼저 적용된다.** 그래야 우리도 그 수정의 덕을 보고, 무엇보다 **깨지면 우리가 먼저 안다** — 보내기 전에.

vendor 클론에서 실행한다. 순서가 중요하다.

cd vendor/ff14-accessibility && git checkout -b kr-port main && git am ../../patches/*.patch ../../overlay/patches/*.patch

`patches/`가 앞이다. 업스트림에 병합되면 그 패치는 여기서 사라지고, 나머지는 그대로 붙어야 한다. 뒤에 두면 받아들여진 뒤 우리 패치들이 전부 어긋난다.

**붙는 자리는 `main`이 아니라 `upstream.json`의 핀이다** — 위 명령의 `main`을 핀 커밋으로 바꿔 읽는다. 업스트림을 올리는 절차는 [docs/upstream-sync.md](../docs/upstream-sync.md).

## `overlay/`가 아니라 여기에 넣는 기준

셋을 다 만족해야 한다.

1. **코드에 한국이 안 나온다.** 시그니처 바이트, `XIVLauncherKR`, KR 시트 ID 같은 것이 있으면 `overlay/`로 간다
2. **다른 클라이언트에서도 고쳐진다.** 독일어·프랑스어·일본어 사용자에게도 이익이어야 한다
3. **업스트림 결정을 뒤집지 않는다.** 뒤집는다면 그건 먼저 물어볼 일이다([commit-rules.md](../docs/commit-rules.md) §3.6)

증거가 KR에서만 나온 것은 괜찮다 — 우리는 KR 클라이언트밖에 없다. 그때는 **어디까지 측정했는지를 커밋 본문에 적는다.**

## 목록

### 0001 — 타이틀 메뉴 항목 수를 메뉴가 완성된 뒤에 말한다

메뉴를 열 때 `PostSetup`에서 읽는데, 그 시점엔 버튼 라벨이 아직 다 안 채워져 있어서 목록이 짧게 잡혔다. 실측(2026-08-18): 개시 안내가 "1 of 5", 12초 뒤 버튼 덤프는 6개(id4~id9), 화살표 이동은 "1 of 6".

**보이는 사람에게는 안 보이는 결함이다** — 화면엔 메뉴가 다 떠 있다. 안 보이는 사람은 이 안내 하나로 메뉴의 크기를 잡는다. "of 5"를 들으면 여섯 번째를 찾지 않는다.

읽기를 매 프레임 도는 `PostUpdate` 경로에 넘겼다. 그쪽은 완성된 메뉴를 읽고 **처음부터 맞는 수를 내고 있었다.** 문장은 그대로고 수만 맞는다. 메뉴가 계속 비면 1초 뒤 "Hauptmenü"만이라도 말한다 — 침묵은 고장과 구분이 안 된다.

기준 대조: 한국 언급 없음(1), `PostSetup` 시점은 언어와 무관하므로 다른 클라이언트도 같음(2, **단 측정은 KR 한 대뿐**), 기존 문장을 안 바꿈(3).

### 0002 — 언어를 한 번만 정하고, 하나 더 넣기 쉽게

`IsGerman`이 bool이라 **모든 호출부가 답을 둘밖에 못 가졌다.** OS 문화권 판정도 그 bool 안에 들어 있어서, 세 번째 언어는 호출부를 전부 건드리지 않고는 표현할 수가 없었다.

`Loc.Current`가 **실제로 쓰는 언어**를 돌려준다 — `Auto`는 이미 OS 문화권으로 풀린 뒤다. `IsGerman`은 거기서 파생돼 그대로 남으므로 **오늘 당장 고칠 호출부는 하나도 없다.**

조회 둘을 `switch` 대신 표로 바꿨다. 언어를 더하는 일이 이제 열거형 한 줄과 표마다 한 행이다 — 다시 읽어야 할 로직이 없다.

**동작은 안 바뀐다.** 독일어 윈도는 그대로 독일어로, 나머지는 그대로 영어로 떨어진다. 전에는 "de가 아니면"이 곧 폴백이었고, 지금은 그게 **폴백이라고 적혀 있을 뿐**이다.

한국어 자체는 여기 없다 — 그릇만 연다. 한국어를 넣는 것은 `overlay/patches/0007`이다.

기준 대조: 한국 언급 없음(1), 프랑스어·일본어를 넣을 때 그대로 쓰인다(2), 동작을 안 바꾸므로 뒤집는 결정이 없음(3).

### 0003 — 서식지와 지역을 붙여 읽던 것

사냥 목표 안내가 서식지와 지역을 구분자 없이 이어 붙였다. KR 실기 로그(2026-08-18)에 그대로 찍혔다.

```
lives in 지평선 가장자리in the area 서부 다날란
```

`가장자리in`을 스크린리더가 **모르는 낱말 하나로 발음한다.** 보이는 사람은 못 느낀다 — 글자로는 그냥 읽힌다. 업스트림이 이 결함을 못 본 이유가 그거일 것이다(추정).

`HuntingArea`는 공백 없이 끝나고 `InArea`·`InAnotherArea`는 공백 없이 시작한다. `InArea`의 다른 호출부 둘은 자기가 `", "`를 앞에 붙이므로, 문자열이 아니라 **이 호출부에 공백을 넣는 게 맞다.** 고친 것은 한 글자다.

**모든 로케일에서 깨진다.** 독일어도 `lebt in Kaktusgrundim Gebiet Ost-Thanalan`이 된다.

**인게임에서 확인했다**(2026-08-18 KR): `lives in 지평선 가장자리 in the area 서부 다날란`으로 끊겨 읽힌다.

기준 대조: 한국 언급 없음(1), 독일어·영어 문자열을 소스에서 읽어 같은 결함을 확인(2, **단 실측은 KR 한 대뿐**), 문장 자체를 안 바꿈(3).

## 보내기

아직 안 보냈다. 막힌 것은 기술이 아니라 절차다 — 업스트림 PR 언어를 아직 안 물어봤다([commit-rules.md](../docs/commit-rules.md) §5).

PR을 조립할 때는 `[업스트림]` 커밋의 `Upstream-Files` 트레일러만 모으면 건드릴 파일 목록이 나온다.
