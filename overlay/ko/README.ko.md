# FF14 접근성 모드 (한국 서버용) 사용 안내

파이널 판타지 14를 한국 서버에서 스크린 리더로 플레이할 수 있게 하는 모드입니다. 이 문서는 모드 설치, 사용법을 다룹니다. 모드가 무엇을 읽어 주는지는 4장의 키 목록에 있습니다.

## 1. 준비물

### 1) 직접 준비해야 하는 것

- Windows
- FINAL FANTASY XIV 한국 서버 클라이언트
- 스크린 리더 **NVDA**
- **Microsoft .NET 10 Desktop Runtime x64**

### 2) .NET 10이 이미 있는지 확인하기

명령 프롬프트에서 확인할 수 있습니다. Win+R을 누르고 `cmd`를 입력해 연 다음 아래를 붙여넣습니다.

dotnet --list-runtimes

`Microsoft.WindowsDesktop.App 10.`으로 시작하는 줄이 출력되면 이미 설치된 것입니다.

Microsoft.WindowsDesktop.App 10.0.11 [C:\Program Files\dotnet\shared\Microsoft.WindowsDesktop.App]

해당 줄이 출력되지 않는다면 [dotnet.microsoft.com/download/dotnet/10.0](https://dotnet.microsoft.com/download/dotnet/10.0)에 접속해 **.NET Desktop Runtime**의 **x64** 설치 파일을 다운로드해 설치합니다. SDK나 ASP.NET Core Runtime이 아닙니다.

### 3) 설치 프로그램이 받아 주는 것

KR Dalamud 업데이터와 vnavmesh는 설치 프로그램이 받아 옵니다. 둘 다 설치 프로그램이 받기 전에 먼저 물어봅니다.

vnavmesh를 설치하지 않아도 나머지 기능은 그대로 동작합니다. 대신 자동 이동 키를 누르면 `자동 이동을 쓸 수 없음. vnavmesh 플러그인이 없거나 불러오지 못함.`이 들립니다.

## 2. 설치

### 1) 받는 것

릴리스 페이지에서 받을 수 있습니다.

https://github.com/dnz3d4c/ff14-ko-accessibility/releases/latest

- `FF14AccessibilityInstaller-KR.exe` — 설치 프로그램
- `FF14Accessibility.zip` — 모드 본체
- `사용 안내.md` — 이 문서

**처음 설치할 때는 셋을 같은 폴더에 둔 채로 실행합니다.** 인터넷에 연결하지 못해도 옆에 있는 압축으로 설치가 끝납니다.

업데이트할 때는 `FF14AccessibilityInstaller-KR.exe` 하나만 있으면 됩니다. 설치 프로그램이 옆에 있는 압축과 인터넷의 최신 판을 비교해서 더 새로운 쪽을 설치합니다.

### 2) 설치 순서

처음 설치할 때는 **설치 프로그램을 두 번 실행하게 됩니다.** 중간에 Dalamud를 받는 단계가 끼어 있고, 그 단계만은 다른 프로그램의 창에서 직접 눌러야 하기 때문입니다. 나중에 업데이트할 때는 한 번만 실행하면 됩니다.

#### ① 게임 종료

설치 전 게임이 꺼져 있어야 합니다.

#### ② 설치 프로그램 실행

`FF14AccessibilityInstaller-KR.exe`를 실행합니다.

※ 서명이 없는 프로그램이라 Windows SmartScreen 경고가 뜰 수 있습니다. [추가 정보] 링크를 클릭하면 [실행] 버튼이 나타납니다.

#### ③ 언어 선택

[언어 선택 / Choose language] 창이 열립니다. 한국어가 선택되어 있습니다. Enter를 누르면 다음 화면으로 넘어갑니다.

#### ④ 설치 시작

설치 프로그램 창에서 [설치 / 업데이트] 버튼에 초점이 갑니다.

창에는 [진행 상황]이라는 이름의 읽기 전용 글 상자가 있고, 설치 프로그램이 하는 말이 여기 쌓입니다. **화살표 키로 읽을 수 있습니다.**

#### ⑤ KR Dalamud 업데이터 질문에 답하기

업데이터가 아직 없을 때만 물어봅니다.

- `KR Dalamud 업데이터가 없다. 게임에 Dalamud를 붙여 주는 프로그램이다.`
- `이 프로그램은 우리가 만든 것이 아니고 재배포하지도 않는다 - 원 저장소에서 직접 받는다.`
- `이것이 없으면 모드를 설치해도 게임에 올라오지 않는다.`
- `KR Dalamud 업데이터를 지금 받을까?`

[예]를 고르면 설치 프로그램이 업데이터를 내려받고 업데이터를 실행합니다.

%LOCALAPPDATA%\KR-Dalamud-Updater\app\Dalamud.Updater.exe

[아니오]를 고르면 설치가 멈춥니다.

#### ⑥ 첫 실행은 여기서 끝납니다

**처음 설치하는 경우, 설치 프로그램은 여기까지만 하고 끝냅니다.** 아직 Dalamud가 없어서 모드를 넣을 자리가 없기 때문입니다.

- 진행 상황 영역에 `한국 서버용 Dalamud가 아직 없다.`가 남고, 이어서 **다음에 무엇을 할지 알려 주는 줄이 셋 더** 남습니다. 업데이터를 실행해 [Check Update]를 누르라는 안내, 업데이터의 경로, 끝나면 설치 프로그램을 다시 실행하라는 안내입니다
- **`== 결과 ==` 블록이 나오지 않습니다.** 다음 절의 성공 표지도, `실패:`로 시작하는 줄도 없습니다
- 그런데도 `끝났다. 자세한 것은 창의 진행 상황 영역에서 읽는다.`라는 대화 상자가 뜹니다

#### ⑦ Dalamud 받기

**게임이 꺼져 있는 상태에서** KR Dalamud 업데이터 창에서 [Check Update] 버튼을 누릅니다. Tab으로 버튼을 훑어 찾을 수 있습니다.

공식 Dalamud를 내려받아 한국 서버용으로 고치는 작업이라 **몇 분 걸립니다.**

#### ⑧ 설치 프로그램 다시 실행

업데이터를 닫고 설치 프로그램을 다시 실행합니다. ②부터 ④까지를 한 번 더 하는 것이고, 이번에는 Dalamud가 있으므로 설치가 끝까지 진행됩니다.

#### ⑨ vnavmesh 질문에 답하기

처음 설치할 때 한 번만 물어봅니다.

- `자동 이동은 vnavmesh 플러그인이 있어야 동작한다.`
- `이 플러그인은 우리가 만든 것이 아니고 재배포하지도 않는다 - 원 저장소에서 직접 받는다.`
- `설치하지 않으면 자동 이동만 빠지고 나머지는 그대로 동작한다.`
- `vnavmesh를 설치할까?`

[예]를 고르면 받아서 설치하고, [아니오]를 고르면 `vnavmesh를 건너뛰었다.`가 남습니다. 이미 설치되어 있으면 묻지 않고 버전을 비교해서 더 새 것이 있을 때만 덮어씁니다.

#### ⑩ 결과 확인

- `== 결과 ==`
- `접근성 모드: ...`
- `vnavmesh: ...`
- `플러그인을 등록하고 켰다.`

**`== 결과 ==`가 보이는 것이 설치가 끝까지 갔다는 표지입니다.** 각 줄이 `새로 설치`, `업데이트`, `이미 최신`, `건너뜀` 중 하나로 끝나면 성공입니다. `실패:`로 시작하는 줄이 있으면 그 줄이 원인을 말합니다.

`== 결과 ==`가 아예 없으면 ⑥의 상태로 돌아간 것입니다. Dalamud를 아직 못 받은 것이므로 ⑦부터 다시 합니다.

※ 설치 프로그램이 `DALAMUD_RUNTIME을 걸었다`와 `이 값은 게임을 새로 켜야 반영된다`를 말한 경우, 게임이 켜져 있었다면 한 번 껐다 켜야 합니다.

### 3) 업데이트 방법

`FF14AccessibilityInstaller-KR.exe`를 다시 실행해 [설치 / 업데이트] 버튼을 누릅니다. 압축을 새로 받아 둘 필요는 없습니다. 다음에 게임을 켤 때 새 판이 올라옵니다.

#### ① 설치 프로그램이 자기 업데이트를 먼저 묻습니다

[설치 / 업데이트] 버튼을 누르면 진행 상황 영역에 `설치 프로그램의 새 버전이 있는지 확인한다 ...`가 먼저 나옵니다. 여기서 갈립니다.

- 이미 최신이면 `설치 프로그램 5.88.0.0 - 이미 최신이다.`가 나오고 설치가 그대로 이어집니다
- 새 버전이 있으면 `새 설치 프로그램 버전이 있다: ...`가 나오고 **[예 / 아니오] 대화 상자가 열립니다.** 내려받을 크기가 몇 메가바이트인지 함께 말해 줍니다

#### ② [예]를 고른 경우 — 창이 닫혔다 다시 열립니다

`설치 프로그램을 ...으로 업데이트한다. 이 창은 지금 닫히고 잠시 뒤 자동으로 다시 실행된다 ...`가 들린 다음 **설치 프로그램 창이 실제로 닫힙니다.**

**창이 사라지는 것이 정상입니다.** 잠시 뒤 새 버전이 자동으로 다시 실행되고, 대화 상자가 하나 뜹니다.

`설치 프로그램을 ...으로 업데이트하고 다시 실행했다.`
`확인을 누르면 설치가 자동으로 이어진다 - 더 할 일은 없다.`

[확인]을 누르면 설치가 알아서 끝까지 갑니다. [설치 / 업데이트] 버튼을 다시 누르지 않아도 됩니다.

#### ③ [아니오]를 고른 경우

`설치 프로그램 업데이트를 건너뛰었다. 지금 버전 그대로 이어서 한다.`가 남고 설치가 그대로 이어집니다. 모드 본체는 이 선택과 관계없이 최신 판으로 설치됩니다.

### 4) 게임이 업데이트된 뒤

게임이 업데이트되어 버전이 올라가면 **KR Dalamud가 새 버전을 지원할 때까지 모드가 실행되지 않습니다.** KR Dalamud는 지원하는 게임 버전을 하나로 고정하고 있어서, 게임 버전이 올라가면 그 값과 어긋납니다.

접속해도 `FF14 Accessibility 버전 ... 준비됨.`이 들리지 않는 상태가 됩니다. 설치가 망가진 것이 아니므로 모드를 다시 설치하지 않아도 됩니다.

#### ① 새 판이 나왔는지 확인하기

**게임이 꺼져 있는 상태에서** KR Dalamud 업데이터를 실행합니다. Win+R을 누르고 아래를 붙여넣으면 됩니다.

%LOCALAPPDATA%\KR-Dalamud-Updater\app\Dalamud.Updater.exe

업데이터 창에서 [Check Update] 버튼을 누릅니다. 새 판이 나와 있으면 내려받아 적용되고, 그 뒤로는 3장의 실행 순서를 그대로 따르면 모드가 다시 실행됩니다.

#### ② 아직 안 나왔을 때

[Check Update]를 눌러도 새 판이 오지 않으면 아직 나오지 않은 것입니다. 나온 뒤에 [Check Update]를 다시 누르면 됩니다.

### 5) 제거

모드만 지우는 것과 Dalamud까지 걷어내는 것이 다릅니다.

#### ① 모드만 지우기

Win+R을 누르고 아래를 붙여넣으면 설치된 플러그인 폴더가 열립니다.

%APPDATA%\XIVLauncherKR\installedPlugins

열린 곳에서 `FF14Accessibility` 폴더를 지웁니다. 다음에 게임을 켜면 모드가 실행되지 않습니다.

vnavmesh도 설치했다면 아래를 붙여넣어 열리는 폴더에서 `vnavmesh` 폴더를 같이 지울 수 있습니다.

%APPDATA%\XIVLauncherKR\devPlugins

※ KR Dalamud 업데이터의 설정에서 프로필 위치를 변경한 적이 있으면 위 두 경로가 다릅니다. 그때는 변경한 위치 아래의 `installedPlugins`와 `devPlugins`를 찾습니다.

#### ② Dalamud까지 걷어내기

**다른 Dalamud 플러그인을 사용하고 있으면 이 단계는 하지 않습니다.** Dalamud를 지우면 그 플러그인들도 함께 동작하지 않습니다.

이 모드만 사용하던 경우에는 아래 폴더를 통째로 지웁니다. Dalamud 본체와 설정이 모두 이 안에 있습니다.

%APPDATA%\XIVLauncherKR

KR Dalamud 업데이터까지 지우려면 아래 폴더도 지웁니다.

%LOCALAPPDATA%\KR-Dalamud-Updater

#### ③ 남는 것

설치할 때 만들어진 `DALAMUD_RUNTIME` 사용자 환경 변수는 위 폴더들을 지워도 남습니다. .NET이 설치된 자리인 `C:\Program Files\dotnet`을 가리키는 값이라 그대로 두어도 다른 프로그램에 영향이 없습니다. 지우려면 윈도의 환경 변수 설정에서 사용자 변수 `DALAMUD_RUNTIME`을 삭제합니다.

## 3. 게임 실행

### 1) 실행 순서

#### ① 게임 실행

한국 공식 런처로 게임을 실행합니다. Win+R을 누르고 아래를 붙여넣으면 됩니다.

"C:\ProgramData\Microsoft\Windows\Start Menu\Programs\FINAL FANTASY XIV - KOREA\FINAL FANTASY XIV - KOREA.lnk"

#### ② 로그인

런처로 로그인 후 게임 시작 버튼을 눌러 게임을 실행합니다.

#### ③ Dalamud 붙이기

**게임이 실행된 상태에서** KR Dalamud 업데이터를 실행합니다. Win+R을 누르고 아래를 붙여넣으면 됩니다.

%LOCALAPPDATA%\KR-Dalamud-Updater\app\Dalamud.Updater.exe

업데이터 창에서 [달라무드 적용] 버튼을 누르면 실행된 게임에 Dalamud가 붙습니다. 업데이터는 게임을 켜 주지 못하므로, 이 버튼을 누르기 전에 게임이 이미 떠 있어야 합니다.

#### ④ 모드가 실행됐는지 확인

모드가 실행되면 `FF14 Accessibility 버전 5 점 88 준비됨.`처럼 음성이 출력됩니다.

들리지 않는 경우는 6장 3절에서 다룹니다.

#### ⑤ 처음이라면 여기서 Ctrl+F1

`Ctrl+F1`을 누르면 지금 상황에서 쓸 수 있는 키와 명령을 말해 줍니다. 화면이 바뀔 때마다 내용이 달라지므로, 처음 보는 창에서 무엇을 할 수 있는지 모를 때 언제든 누르면 됩니다.

### 2) 안내 언어 고르기

- `/acc lang ko` — 한국어(기본값)
- `/acc lang en` — 영어
- `/acc lang de` — 독일어
- `/acc lang auto` — Windows 언어를 따라감

### 3) 설정 메뉴

`Shift+F9`로 설정 메뉴를 열 수 있습니다.

- `소리` — 길안내 신호음과 경유지·도착 알림음의 **음량**을 조절합니다. 음량을 0으로 두면 그 소리가 나지 않습니다. 켜고 끄는 항목으로 있는 것은 `기술 준비됨` 하나입니다. 각 소리가 무엇을 나타내는지는 4장 4절과 4장 6절에 있습니다
- `안내` — 방향 안내, 대상 변경, 대상 HP, 적 기술 시전, 지도 표식, 오류 메시지, 알림 메시지를 켜고 끄기
- `로그 채널` — 채널별로 읽어 줄지 정하기
- `로그 탭` — 게임 탭을 따라가는 로그 시스템을 쓸 때만 나옵니다
- `로그 시스템` — 두 로그 시스템 중 하나 고르기. 이 행은 지금 고른 것을 달고 들립니다(`로그 시스템: 기존, 고정 채널`)

조작 키는 다음과 같습니다.

- 숫자패드 8 또는 위쪽 화살표 — 위로
- 숫자패드 2 또는 아래쪽 화살표 — 아래로
- 숫자패드 6, 숫자패드 0, 오른쪽 화살표 — 고르기, 한 단계 안으로
- 숫자패드 4 또는 왼쪽 화살표 — 한 단계 이전으로
- 숫자패드 마침표, Delete, ESC — 메뉴 닫기
- Home, End — 목록의 처음, 끝
- 글자나 숫자 키 — 그 글자로 시작하는 항목으로 건너뛰기

## 4. 키

### 1) 키 이름을 부르는 방식이 세 가지입니다

같은 키를 세 곳이 서로 다르게 부릅니다. 이 차이를 모르면 설정 파일에서 키를 바꿀 수 없기 때문에 먼저 짚습니다.

- **이 문서**는 로마자로 적습니다 — `Ctrl+F1`, `Shift+F9`, `Page Down`, `ESC`
- **모드가 말할 때**는 한글로 읽습니다 — `컨트롤 F1`, `페이지 다운`, `숫자패드 3`
- **설정 파일에 적는 값은 독일어입니다** — `Strg+F1`, `BildAb`, `Numpad3`

설정 파일에서 **Ctrl, Shift, Alt는 영어로 적어도 됩니다.** 그 뒤에 오는 키 이름만 독일어이고 쓸 수 있는 이름이 정해져 있습니다.

| 이 문서 표기 | 설정 파일에 적는 값 |
|--------------|---------------------|
| Ctrl | `Strg` 또는 `Ctrl` |
| Shift | `Umschalt` 또는 `Shift` |
| Alt | `Alt` |
| Page Up / Page Down | `BildAuf` / `BildAb` |
| End | `Ende` |
| Delete | `Entf` |
| ESC | `Escape` |
| Enter | `Return` |
| 위쪽 화살표 / 아래쪽 화살표 | `Up` / `Down` |
| 왼쪽 화살표 / 오른쪽 화살표 | `Left` / `Right` |
| F1~F12 | `F1`~`F12` |
| 숫자패드 숫자 | `Numpad0`, `Numpad2`, `Numpad3`, `Numpad4`, `Numpad5`, `Numpad6`, `Numpad8` |
| 숫자패드 마침표 | `NumpadKomma` |
| 글자 | `N`, `H`, `L` |
| 쉼표, 마침표, 더하기 | `,` / `.` / `+` |

즉 `Ctrl+Page Down`은 설정 파일에 `Strg+BildAb`로 적습니다.

**이 표에 없는 이름을 적으면 그 키는 동작하지 않습니다.** 특히 Home에 해당하는 `Pos1`과 글자 `F`는 표에 없습니다. 6장 1절 ②가 그 때문에 생긴 문제입니다.

※ 숫자패드에 할당된 단축키(숫자패드 3, 숫자패드 5 등)를 사용하려면 넘락을 켜야 합니다. 설정 메뉴와 기술 메뉴는 넘락이 꺼져 있어도 다룰 수 있습니다.

### 3) 대상 찾기

- **Page Down** — 다음 대상 알려 주고 지정하기
- **Page Up** — 이전 대상 알려 주고 지정하기
- **Ctrl+Page Down** — 다음 분류로 옮기기
- **Ctrl+Page Up** — 이전 분류로 옮기기
분류는 스무 개이고 `Ctrl+Page Down`을 누를 때마다 변경된 분류 이름을 읽습니다.

전체, NPC, 상인, 적, 아군, 플레이어, 사물, 임무, 퀘스트 NPC, 퀘스트 사물, 퀘스트 적, 채집 지점, 돌발 임무, 토벌 대상, 낚시터, 에테라이트, 퀘스트 목표, 받을 수 있는 퀘스트, 길드 의뢰, 경유지입니다.

딥 던전 안에서는 다섯으로 바뀝니다. 전체, 방, 보물상자, 석탑, 적입니다. 석탑은 부활 석탑과 전송 석탑 둘을 함께 담습니다.

※ `경유지`에는 지역 출구가 포함됩니다.

### 4) 이동과 길안내

- **숫자패드 3** — 자동 이동 켜고 끄기. vnavmesh가 필요합니다
- **Ctrl+숫자패드 3** — 길안내 켜고 끄기
- **+** — 지정한 대상 따라가기 켜고 끄기. vnavmesh가 필요합니다
- **Ctrl+숫자패드 5** — 경로 미리 듣기
- **숫자패드 5** — 길안내가 가리키는 쪽으로 한 번 돌기
- **Ctrl+Shift+F1** — 클립보드에 복사해 둔 좌표로 이동하기
- **Ctrl+Shift+F2** — 지금 서 있는 자리의 좌표를 클립보드로 복사하기
- **Ctrl+Shift+F6** — 발자취 기록 켜고 끄기
- **N** — 방향 안내 켜고 끄기
#### 이 갈래의 소리가 무엇을 나타내나

**목표 방향 신호음**은 지정한 목표가 어느 쪽에 있는지 계속 알려 줍니다.

- 목표가 왼쪽에 있으면 소리도 왼쪽에서 나고 오른쪽이면 오른쪽에서 납니다
- 앞뒤는 소리의 높이로 구분합니다. 목표가 정면일 때 가장 높고 뒤로 돌아갈수록 낮아집니다
- 목적지에 **가까워질수록 소리가 커집니다**

**길안내**를 켜면 직접 걸어가는 동안 장애물을 피해 갈 방향을 알려 줍니다. 지나야 할 지점마다 소리가 나고, 지금 보고 있는 쪽을 기준으로 어느 쪽으로 가야 하는지 말해 주며, 도착하면 도착 소리가 납니다.

**경로 미리 듣기**는 걷지 않고 경로만 들려줍니다. `에테라이트까지 경로, 62미터: 북 방향 25미터 …`처럼 구간마다 방향과 거리를 이어서 말합니다.

**발자취**는 길 정보에 빠져 있는 구간을 한 번 직접 걸어서 기록해 두는 기능입니다. 나중에 자동 이동이 같은 자리에서 막히면 기록해 둔 발자취를 따라갑니다.

※ **길안내, 자동 이동, 따라가기는 한 번에 하나만 켜집니다.**

※ **토벌수첩이 열려 있고 마물 줄에 초점이 있으면 `숫자패드 3`이 다른 일을 합니다.** 자동 이동 대신 그 마물을 찾아 주는데, 가까이 있으면 그리로 걸어가고 없으면 어디에 사는지 말해 줍니다.

※ `+`는 숫자패드의 `+`가 아니라 일반 자판의 `+`입니다.

※ **`N`은 한국 클라이언트에서 제작수첩과 겹칩니다.** 자세한 것은 6장 1절에 있습니다.

게임이 원래 쓰는 키 중 자주 함께 쓰는 것은 `F`(대상 쪽으로 돌기)와 `W`(전진)입니다.

### 5) 읽어 주기와 정보

- **Ctrl+F1** — 지금 쓸 수 있는 키와 명령 말해 주기
- **Ctrl+F2** — 지금 초점이 있는 창 알려 주기
- **Ctrl+F10** — 지금 열려 있는 메뉴 읽기. 퀘스트 목록이 열려 있으면 퀘스트를 읽고, 캐릭터 생성의 외모 단계에서는 지금까지 고른 외모를 한 번에 읽습니다
- **Ctrl+F11** — 말하기 즉시 멈추기
- **Ctrl+Delete** — 내 HP와 MP 말해 주기
- **Ctrl+End** — 채집가의 GP 말해 주기
- **Ctrl+L** — 레벨과 남은 경험치 말해 주기
- **Shift+L** — 휴식 구역과 휴식 보너스 말해 주기
- **Ctrl+F** — 어느 딥 던전의 몇 층인지 말해 주기
- **Shift+F9** — 설정 메뉴 열고 닫기
- **Ctrl+F3** — 소지품과 중요 아이템 읽기. 건네주기 창이 열려 있으면 소지품 전체가 아니라 **낼 수 있는 물건만** 읽습니다
- **Shift+F3** — 소지금 말해 주기
- **Ctrl+F4** — 토벌수첩 읽기. **토벌수첩 창이 열려 있어야 합니다.** 닫혀 있으면 `토벌수첩이 열려 있지 않음.`이라고만 말합니다
- **Ctrl+F12** — 들어온 알림·초대 수락하기
**`Ctrl+F`는 지금 동작하지 않습니다.** 자세한 것은 6장 1절에 있습니다.

### 6) 전투

- **Ctrl+Shift+F3** — 범위 경고 켜고 끄기. **기본값은 꺼짐**입니다
- **Shift+F7** — 열려 있는 전리품 입찰 읽기
- **Shift+F8** — 전리품 입찰 창으로 초점 옮기기. 입찰 창에서 숫자패드로 선입찰, 입찰, 포기를 고릅니다
#### 이 갈래의 소리가 무엇을 나타내나

**HP와 MP는 소리로도 나갑니다.** 남은 양이 소리가 나는 위치로 바뀝니다.

- 가득 차 있으면 오른쪽, 절반이면 가운데, 다 떨어졌으면 왼쪽에서 납니다. 10퍼센트 단위로 옮겨 갑니다
- 소리의 높이가 올라가면 회복한 것이고 내려가면 피해를 입거나 소모한 것입니다
- **HP와 MP는 소리 자체가 달라서 한꺼번에 나도 구별됩니다.** HP는 높고 둥근 소리, MP는 낮고 유리 같은 소리입니다
- **HP가 25퍼센트 아래로 내려가면 HP 소리가 떨립니다.** MP 소리는 떨리지 않습니다

**적을 지정하면 짧은 소리가 납니다.** 대상의 HP는 백분율로 말해 줍니다. 게임이 적의 HP를 숫자로 보여 주지 않기 때문입니다.

**범위 경고**를 켜면 예고된 범위 안에 서 있는 동안 반복해서 소리가 나고, 빠져나오면 소리가 나지 않습니다.

**기술 준비됨**은 재사용 대기가 끝났을 때 소리와 이름으로 알려 줍니다. `/acc cd`로 켜고 끕니다.

※ 범위 경고가 기본으로 꺼져 있는 이유는 경고할 범위의 모양을 알아내는 방식이 아직 게임 안에서 완전히 확인되지 않아서입니다. 전투 중에 틀린 경고가 나는 것이 경고가 없는 것보다 나쁘다고 보았습니다.

※ 입찰 창으로 초점을 옮기는 것은 키를 눌러야 합니다.

### 7) 장비

- **Ctrl+F6** — 착용 중인 장비 읽기
- **Ctrl+F7** — 가장 좋은 장비를 한 번에 착용하기
- **Ctrl+F8** — 무작위 외모 고르기. 캐릭터 생성에서만 동작합니다
※ 게임 화면에서 이 기능의 이름은 `최강 장비`인데 모드는 `추천 장비 착용됨.`으로 시작하는 문장을 말합니다. 뒤에 몇 개가 바뀌었는지가 붙습니다. 같은 기능입니다.

### 8) 기술 메뉴

- **Ctrl+F9** — 첫 단축바 읽기. 1번부터 0번 키에 할당된 값을 음성으로 출력합니다
- **Ctrl+숫자패드 0** — 기술 메뉴 열고 닫기
기술 메뉴가 열려 있는 동안 숫자패드는 메뉴를 다루는 데만 쓰입니다. 아래 키들은 원래 게임에서 이동과 확인·취소에 쓰이는 것이라 메뉴가 열려 있는 동안에는 게임에 전달되지 않습니다.

- **숫자패드 8, 숫자패드 2** — 목록 넘기기
- **숫자패드 4, 숫자패드 6** — 목록 바꾸기. 목록은 다섯입니다. 기술, 아이템, 퀘스트 아이템, 일반 기술, 탈것입니다
- **숫자패드 0** — 고르기. 기술을 고르면 놓을 수 있는 키 목록으로 넘어갑니다. 거기서 숫자패드 8과 2로 키를 고르고 숫자패드 0을 한 번 더 누르면 그 키에 놓입니다
- **숫자패드 마침표** — 한 단계 이전으로 가기, 또는 메뉴 닫기

### 9) 로그 되읽기

- **Alt+Page Up** — 이전 채널로 옮기기
- **Alt+Page Down** — 다음 채널로 옮기기
- **Shift+Page Up** — 고른 채널에서 더 오래된 줄 읽기
- **Shift+Page Down** — 고른 채널에서 더 새로운 줄 읽기
- **Shift+Home** — 채널의 맨 처음으로 가기
- **Shift+End** — 채널의 맨 끝으로 가기
- **Alt+Home** — 이전 로그 탭으로 옮기기
- **Alt+End** — 다음 로그 탭으로 옮기기
- **Enter** — 방금 읽은 줄에 같은 채널로 답장하기

채널을 옮기면 채널 이름과 그 안에 쌓인 줄 수를 말해 줍니다. 채널은 대화, 말하기, 외치기, 파티, 연합 파티, 귓속말, 자유부대, 시스템, 전리품입니다.

**`Shift+Home`·`Shift+End`·`Alt+Home`·`Alt+End` 넷은 기본 설정에서 쓸 수 없습니다.** 두 번째 로그 시스템에만 있는 기능인데 기본값이 기존 시스템이라, 누르면 `이 키는 신규 로그 시스템 전용이라 지금은 쓸 수 없음.`이 들립니다. 자세한 것은 6장 1절 ②에 있습니다.

**답장이 되는 채널은 넷입니다.** 말하기, 파티, 자유부대, 귓속말입니다. 외치기와 연합 파티에서는 그 채널로 보낼 수 없다고 말해 주고, 대화·시스템·전리품에서는 아무 일도 일어나지 않습니다. 되읽기를 마지막으로 만진 지 30초가 지나면 채널을 바꾸지 않고 지금 채널 그대로 입력란이 열립니다.

※ `Alt+Home`과 `Alt+End`로 로그 탭을 바꾸는 것은 모드가 새로 만든 기능이라, 게임의 단축키 설정에서는 이 두 키를 찾을 수 없습니다.

### 10) 감정 표현

- **Shift+F4** — 이전 감정 표현 알려 주기
- **Shift+F5** — 다음 감정 표현 알려 주기
- **Shift+F6** — 고른 감정 표현 실행하기
### 11) 카드 대결

- **Ctrl+Shift+F4** — 판 읽기
- **Ctrl+Shift+F5** — 내 패 읽기
### 12) 플러그인 목록

- **Shift+F1** — 다음 플러그인 알려 주기
- **Shift+F2** — 이전 플러그인 알려 주기
- **Shift+F12** — 고른 플러그인의 설정 열기
### 13) 진단

- **Ctrl+F5** — 열려 있는 창의 내부 구조를 바탕 화면에 파일로 저장하기. 어떤 창이 왜 안 읽히는지 문제를 파악하는 데 도움이 됩니다

### 14) 게임 키와 겹치는 것

모드 키 몇 개는 게임이 이미 사용하는 키와 같습니다. 겹치는 개수는 접속할 때마다 말해 줍니다.

- **Page Up과 Page Down**은 카메라 확대·축소를 겸합니다
- **Ctrl+End**는 카메라 설정 저장을 겸합니다
- **숫자패드 5**는 카메라를 대상 쪽으로 돌리는 기능을 겸합니다. 이 키를 누를 때 카메라까지 같이 움직이지 않도록 모드가 이 키를 받고 게임에는 넘기지 않습니다

**한국 클라이언트에서 하나가 더 겹칩니다.** 방향 안내를 켜고 끄는 `N`이 제작수첩을 여는 키와 같습니다. 위의 셋과 달리 실제로 창이 열리기 때문에 그냥 둘 수 없는 겹침입니다. 자세한 것은 6장 1절에 있습니다.

## 5. 명령어

키 대신 명령어로 쓸 수 있는 기능이 있습니다. 대화 입력란에 그대로 입력하면 됩니다.

- `/acc help` — 도움말 알려 주기
- `/acc nav` — 대상까지의 방향과 거리 말하기
- `/acc set` — 지금 지정한 대상을 계속 따라다니며 안내하기
- `/acc clear` — 추적 중인 대상 지우기
- `/acc near` — 가까이 있는 대상 나열하기
- `/acc status` — HP와 MP 말하기
- `/acc ui` — 열려 있는 메뉴 읽기
- `/acc win` — 초점이 있는 창 알려 주기
- `/acc keys` — 게임 단축키 설정을 바탕 화면에 저장하기
- `/acc stop` — 말하기 멈추기
- `/acc fish` — 이 지역의 낚시터 알려 주기
- `/acc fishhere` — 지금 서 있는 자리를 낚시터로 기억하기
- `/acc fishobj` — 50미터 안의 사물을 가까운 순으로 훑어 기록에 남기기. 음성으로는 찾은 개수만 말합니다. 낚시터를 못 찾을 때 원인을 알아보는 진단용입니다
- `/acc gather` — 이 지역의 채집 지점 알려 주기
- `/acc gathergo` — 가장 가까운 채집 지점으로 이동하기
- `/acc trails` — 이 지역에 기록해 둔 발자취 나열하기
- `/acc trail del <번호>` — 기록해 둔 발자취 지우기. 번호는 `/acc trails`가 말해 주는 그 번호입니다
- `/acc cd` — 기술 준비됨 안내 켜고 끄기. `/acc cooldowns`도 같습니다
- `/acc soundtest` — 모드가 쓰는 소리를 차례로 들려주기. 4장 4절과 4장 6절의 설명과 짝지어 들으면 됩니다
- `/acc compat` — 한국 클라이언트에서 어느 기능이 어떤 방식으로 동작하는지 말해 주기. **한국 서버판에만 있습니다.** 무언가 이상할 때 문제를 알리면서 이 내용을 함께 보내면 원인을 찾는 데 쓰입니다
- `/acc lang ko` — 모드 안내 메시지 언어 바꾸기. `ko`, `en`, `de`, `auto`를 사용할 수 있습니다
- `/acc dump <창 이름>` — 창의 구조를 바탕 화면에 저장하기

## 6. 문제 해결

### 1) 지금 고쳐지지 않은 것

아래 세 가지는 이미 알려진 문제이고 **아직 고쳐지지 않았습니다.**

#### ① N 키가 제작수첩을 같이 엽니다

`N`은 방향 안내를 켜고 끄는 키인데 **한국 클라이언트에서는 `N`이 제작수첩 키입니다.** 그래서 방향 안내를 켜고 끌 때마다 제작수첩이 같이 열립니다.

설정 파일에서 다른 키로 옮길 수 있습니다. 4장 2절의 방법으로 `KeyToggleHeading` 값을 바꾸면 됩니다.

#### ② 기본 키 몇 개가 동작하지 않습니다

원인이 둘이고 고치는 방법이 서로 다릅니다.

**하나 — 모드가 키 이름을 못 알아봅니다.**

`Ctrl+F`(어느 딥 던전의 몇 층인지)를 누르면 아무 일도 일어나지 않습니다. 원인은 4장 1절의 이름 표입니다. 여기 처음부터 지정되어 있는 `F`가 그 표에 없어서 모드가 키 이름을 알아보지 못합니다. **표에 있는 다른 키로 바꾸면 되살아납니다.**

"KeyDeepFloor": "Strg+Numpad2",

이것은 한국 서버만의 것이 아니라 원본이 갖고 있는 결함이고, 독일어와 영어를 쓰는 플레이어도 함께 겪습니다.

**둘 — 로그 시스템이 달라서 막힙니다.**

`Shift+Home`(채널 맨 처음), `Shift+End`(채널 맨 끝), `Alt+Home`(이전 로그 탭), `Alt+End`(다음 로그 탭) 넷은 **두 번째 로그 시스템에만 있는 기능**입니다. 기본값이 기존 시스템이라 이 넷을 누르면 이렇게 들립니다.

`이 키는 신규 로그 시스템 전용이라 지금은 쓸 수 없음.`

**키를 바꿔도 이건 안 풀립니다.** 3장 3절의 설정 메뉴에서 `로그 시스템`을 두 번째 것으로 바꿔야 쓸 수 있습니다.

※ `Shift+Home`과 `Alt+Home`은 여기에 더해 이름 표 문제도 함께 갖고 있습니다. 처음 지정된 `Pos1`이 표에 없기 때문입니다. 그래서 이 둘은 **로그 시스템을 바꾼 다음에 키까지 바꿔야** 쓸 수 있습니다.

#### ③ 알림 수락 안내가 독일어로 들립니다

`Ctrl+F12`로 초대를 수락하는 기능의 **안내 문장에 키 이름이 독일어로 박혀 있습니다.** 한국어로 맞춰 두어도 이렇게 들립니다.

`알림. Strg+F12 눌러 수락한다.`

`Strg`는 `Ctrl`을 뜻합니다. 안내 문구만 그런 것이고 **기능은 정상 동작합니다.** 독일어가 그대로 들리는 자리는 이 한 줄뿐입니다.

### 2) 그 밖에 자주 겪는 것

#### ① 자동 이동이 안 될 때

숫자패드 3을 눌렀을 때 들리는 말로 원인이 갈립니다.

- `자동 이동을 쓸 수 없음. vnavmesh 플러그인이 없거나 불러오지 못함.` — vnavmesh가 아직 없습니다. 설치 프로그램을 다시 실행해 설치할 수 있습니다
- `길 정보 불러오는 중, 42 퍼센트. 잠시 뒤 다시 해라.` — vnavmesh는 동작하고 있습니다. 지역에 처음 들어가면 길 정보를 새로 만드느라 몇 분 걸립니다. 숫자 자리에는 그때의 진행률이 들어갑니다
- `길 정보가 아직 준비 안 됨. 잠시 뒤 다시 해라.` — vnavmesh는 동작하지만 이 지역의 길 정보가 아직 없습니다

하우징 구역에서는 집이 다 나타난 뒤에 길 정보를 다시 만듭니다. 게임이 집을 다 불러오기 전에 만들면 울타리 같은 것이 빠진 채로 만들어져서 자동 이동이 거기에 부딪히기 때문입니다. 그동안은 기다리라고 말해 줍니다.

#### ② 캐릭터 생성에서 한국어가 아닌 안내가 들릴 때

캐릭터 생성의 **얼굴과 머리 모양 묘사는 아직 한국어로 옮기지 못했습니다.** 영어로 들립니다.

#### ③ 세는 말이 영어로 들릴 때

토벌수첩처럼 `3 of 48` 형태로 개수를 세는 자리 하나는 **일부러 영어로 두었습니다.** 한국어 어순인 `48 중 3`으로 바꾸면 토벌수첩이 한 줄도 읽히지 않게 됩니다.

#### ④ 기동할 때 오류가 하나 뜰 때

접속할 때 vnavmesh 설정 파일이 없다는 오류가 **하나 나는 것이 정상입니다.** vnavmesh가 아직 자기 설정을 저장한 적이 없을 뿐이고 기본값으로 그대로 동작합니다.

#### ⑤ 설치 프로그램이 KR Dalamud 업데이터를 받지 못할 때

진행 상황 영역에 아래 같은 줄이 남았다면 설치 프로그램이 인터넷에서 업데이터를 가져오지 못한 것입니다.

- `GitHub에 연결하지 못했다: ...`
- `GitHub 응답이 없다.`
- `최신 판에 "Portable" 압축이 없다.`

셋 다 뒤에 `업데이터는 직접 받아야 한다.`가 이어집니다. 앞의 둘은 잠시 뒤에 설치 프로그램을 다시 실행하면 대개 해결됩니다. 세 번째까지 나오면 업데이터를 직접 받아야 합니다. [github.com/MiqoKR/kr-dalamud-updater](https://github.com/MiqoKR/kr-dalamud-updater)의 최신 릴리스에서 이름에 `Portable`이 들어간 압축 파일을 받아 아래 폴더에 풀면 설치 프로그램이 그 자리를 그대로 씁니다.

%LOCALAPPDATA%\KR-Dalamud-Updater\app

압축 안에는 파일이 셋 들어 있고 **셋을 같은 폴더에 함께 두어야 합니다.** 설정 파일이 실행 파일 옆에 없으면 업데이터가 자기 자신을 업데이트하지 못합니다.

### 3) 모드가 아예 뜨지 않을 때

접속했는데 `FF14 Accessibility 버전 ... 준비됨.`이 들리지 않으면 아래를 차례로 확인할 수 있습니다.

- ① **NVDA가 켜져 있는지** 확인합니다
- ② 게임을 먼저 켜고 업데이터를 실행했는지 확인합니다
- ③ 업데이터 창에서 [달라무드 적용]을 눌렀는지 확인합니다
- ④ 설치 프로그램을 다시 실행해 진행 상황 영역에 `== 결과 ==`가 있는지 확인합니다. `실패:`로 시작하는 줄이 섞여 있으면 그 줄이 원인을 말합니다
- ⑤ **.NET 10이 설치되어 있는지** 1장 2절의 방법으로 확인합니다. 설치 프로그램은 .NET 10이 없어도 `== 결과 ==`까지 정상으로 끝내므로, ④가 통과했더라도 여기서 걸려 있을 수 있습니다
- ⑥ `DALAMUD_RUNTIME` 안내가 나왔던 적이 있다면 게임을 완전히 껐다가 다시 켭니다. 이 값은 게임이 시작할 때만 읽히기 때문입니다
