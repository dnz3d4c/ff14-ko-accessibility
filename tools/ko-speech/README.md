# ko-speech — `Pick` 밖에서 새는 외국어 리터럴을 고정한다

`tools/strings-golden`이 **독일어·영어가 안 변했나**를 지킨다면, 이쪽은 반대를 묻는다 — **독일어·영어가 왜 이 자리에 맨몸으로 있나.**

## 왜 생겼나

사용자가 인게임에서 `불멸대 막사 방향 통로, Übergang, 54미터, 왼쪽`을 들었다. 그 `Übergang`은 소스에 맨 리터럴로 박혀 있어서 카탈로그에도 스냅샷에도 없었고, **기존 검사 넷이 하나도 못 잡았다.**

`Loc.Pick`이 `Korean => ko ?? en`이라(`Loc.cs:94-99`) 한국어가 없으면 조용히 영어가 나간다. 그런데 애초에 `Pick`을 안 거치면 그 조용한 폴백조차 없다 — 독일어가 그대로 나간다. 같은 부류로 `NavCategory.Fates => "FATEs"`가 있었다. 형제 열다섯이 전부 `Pick(...)`인데 혼자 맨 리터럴이라 한국어 문장 안에서 `FATEs`로 나갔다(현황판 §4-3).

## 무엇을 하나

판정을 **두 갈래로 나눈다.** 한 규칙으로 묶으면 오탐이 섞여 둘 다 죽는다.

| 갈래 | 무엇을 보나 | 왜 나눴나 |
|------|-------------|-----------|
| `umlaut` | `[äöüßÄÖÜ]`를 가진 리터럴이 `Pick`/삼항 밖에 있다 | 이 문자는 한국어에도 명령어에도 안 나와서 문자셋만으로 갈린다 |
| `sibling` | `switch` 가지나 배열 초기화에서 형제가 `Pick`인데 자기만 맨 리터럴이다 | `Aethernet`·`Ort`·`FATEs`는 움라우트가 없어 이 규칙으로만 잡힌다 |

    uv run --no-project python tools/ko-speech/ko_speech.py           # 대조
    uv run --no-project python tools/ko-speech/ko_speech.py --write   # 골든 갱신

`run\check.bat` 1단계 pytest가 같이 돌린다.

## 오탐 넷 — 앞 셋은 계산으로 갈리고 넷째는 오탐이 아니다

1. **비교 키** — `p.TypeLabel is "Ätheryt" or "Aethernet"`(`PlacesService.cs:425`). 발화가 아니라 식별자다. 리터럴만 바꾸면 에테라이트 분류가 예외도 로그도 없이 죽는다
2. **로그** — `_log.Info($"[Nav] ...")`. 감싸는 호출을 바깥으로 훑어서, 한 겹 더 들어가 있어도 잡는다
3. **파서가 모양을 못 읽은 언어 분기** — `AccessibilityStrings.cs`의 중첩 삼항. 한국어가 이미 있는데 파서가 모양을 못 읽을 뿐이라 `strings-golden`이 세는 미해석 목록과 같은 부류다
4. **`ColorNamer.cs`의 `De ? "gräuliches" : "greyish"`** — **이건 오탐이 아니라 진짜 결함이다.** 그 파일은 `De`라는 자기 별칭을 둬서 표식(`IsGerman`)에 안 잡히고 한국어가 0곳이다. 그래서 3번 규칙이 일부러 별칭을 안 본다 — 여기 걸려야 맞다(W-44)

## 골든이 판단을 담는다

넷으로 안 갈리는 잔여분을 `golden/speech-sites.json`에 고정하고, 늘면 실패시킨다.

**골든에 넣는 것은 판단이라 `why`가 비어 있으면 검사가 빨개진다.** 다음 사람이 그 줄을 근거 없이 믿는 것을 막는다. `--write`는 기존 `why`를 그대로 옮겨 적고 새 자리만 빈칸으로 남기므로, 갱신 한 번에 사람이 쓴 판단이 날아가지 않는다.

빨개지면 셋 중 하나고, 어느 쪽인지는 사람이 정한다.

- 발화에 외국어가 새기 시작했다 → 고친다
- 통과시킬 자리가 새로 생겼다 → `--write`로 갱신하고 **`why`를 채운다**
- 그 자리가 없어졌다 → `--write`로 갱신한다

골든에는 **통과시킬 것과 아직 못 고친 결함이 같이 산다.** 어느 쪽인지는 `why`가 말한다 — `ColorNamer`가 차지한 자리들은 W-44가 고칠 결함이지 통과가 아니다.

## 한계

- **캐릭터 생성 묘사 두 파일은 범위 밖이다**(`OUT_OF_SCOPE`). 3,023건이 통째로 W-12 소유라, 여기서 다시 세면 상태가 두 벌이 되고 골든이 안 읽힌다
- **움라우트가 없는 독일어는 `sibling` 갈래로만 잡힌다.** `Ort`처럼 형제가 없는 자리에 홀로 앉아 있으면 못 본다
- **축자 문자열(`@"..."`)과 중첩 보간은 못 읽는다.** `tools/ko-apply`·`tools/strings-golden`과 같은 한계고, 그 자리들은 손 케이스로 따로 관리된다
