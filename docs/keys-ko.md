# 단축키 한국어 표

- 작성: 2026-08-17
- 출처: `vendor/ff14-accessibility/FF14Accessibility/Configuration.cs`의 기본값 52개 전수
- 독일어 키 이름을 옮긴 것이다. 설정 파일에는 여전히 독일어로 적혀 있다
- **사용자에게 주는 표기는 여기가 아니라 [overlay/ko/README.ko.md](../overlay/ko/README.ko.md) §5가 갖는다.** 여기는 개발 쪽 실측 기록이다

## 독일어 키 이름 대응

| 설정 파일 표기 | 실제 키 |
|----------------|---------|
| Strg | Ctrl |
| Umschalt | Shift |
| BildAuf / BildAb | Page Up / Page Down |
| Pos1 / Ende | Home / End |
| Entf | Delete |
| Numpad0~9 | 숫자패드 0~9 |

**숫자패드를 쓰려면 넘락을 켜야 한다.** 끄면 숫자패드가 방향키로 바뀌어 모드가 못 알아본다.

**모드가 이 이름들을 독일어 그대로 발음한다.** `알림. Strg+F12 눌러 수락한다.`처럼 나간다. 위 표를 사람이 읽는 것과 별개로, 모드는 아직 옮겨서 말하지 않는다 — 현황판 [§4-7](status.md#4-7-모드-키-이름이-독일어로-발화된다--모든-언어-w-21) (W-21).

## KR에서 게임과 겹치는 키

`N`(방향 안내)이 KR에서 **제작 메뉴를 연다.** 업스트림은 `N`을 "유일하게 비어 있는 낱글자"로 보고 배정했는데 KR에서는 그 전제가 틀렸다. 어느 키로 옮길지는 사용자 판단이라 현황판 [§7 D-2](status.md#7-판단이-필요한-것)에 있다.

나머지 겹침 넷(PageUp·PageDown·Ctrl+End·Numpad5)은 카메라 조작이라 **전맹 플레이에 결과가 없다.** 근거는 현황판 [§4-1](status.md#4-1-키-충돌--5건-중-kr-고유는-1건-w-03) (W-03).

## 지금 안 되는 것

- `Ctrl+F` (깊은 던전 층), `Shift+Home` (로그 되읽기 맨 처음), `Alt+Home` (이전 로그 탭) — 키 이름 파서가 `Pos1`(Home)과 `Strg+F`를 모른다. 기동 로그에 `Unbekannte Tastenangabe` 경고로 찍힌다. 현황판 [§4-2](status.md#4-2-기본-바인딩-3개가-조용히-죽어-있다-w-04) (W-04)

## 호환 상태 확인

`/acc compat` — 지금 어떤 답이 게임에서 오고 어떤 답이 KR 호환 계층에서 오는지 말해 준다. 대화 입력란에 치는 명령이다.

기동할 때도 **게임과 답이 달라질 수 있는 경우에만** 한 줄이 들린다. 현재 KR에서는 기어세트 마크 한 줄이다("Gearset marks go by item ID") — 같은 장비 두 개 중 하나만 세트에 들어 있어도 둘 다 표시된다는 뜻이다. 근거는 `docs/environment.md` §5.

## 메뉴 이동

- **화살표 키** — 목록·대화상자 이동. 캐릭터 생성 외모 격자는 게임이 화살표를 무시하므로 **모드가 직접 넘긴다**
- **숫자패드 8 / 2 / 4 / 6** — 게임 자체 메뉴 이동. 서버(데이터센터) 선택 화면은 이걸 써야 읽어준다
- **Enter** — 확인

## 이동과 길찾기

vnavmesh 플러그인이 있어야 동작하는 항목이 있다. **깔았고 사전 검증은 통과했지만, 게임 안에서 실제로 적재되는지는 아직 확인 안 했다.** 넘패드3을 눌렀을 때 들리는 말로 판정한다 — `docs/kr-runtime-setup.md` §10.

| 키 | 하는 일 |
|----|---------|
| Page Down / Page Up | 주변 오브젝트 다음 / 이전 |
| Ctrl+Page Down / Ctrl+Page Up | 오브젝트 카테고리 전환 |
| 숫자패드3 | 목표로 자동 이동 켜기/끄기 (vnavmesh 필요) |

| `+` | 대상 따라가기 켜기/끄기 (vnavmesh 필요). 숫자패드 아닌 일반 `+` |

## 캐릭터 생성 외모 단계

실측으로 확인한 순서다.

1. **화살표 키** — 항목 값 바꾸기. 방향 넷 다 ±1이고 양 끝에서 멈춘다. "13 중 49" 식으로 읽는다
2. **Ctrl+F10** — 지금까지 고른 외모 전체 듣기
3. **Ctrl+F8** — 무작위로 다시 굴리기
4. **Enter** — 확인

이 화면의 항목 21개(2026-08-17 KR 실측): 얼굴 유형, 얼굴 윤곽, 눈, 눈썹, 코 모양, 입 모양, 머리 모양, 머리 색, 피부색, 눈동자 색, 눈동자 크기, 입술 색, 얼굴 치장, 얼굴 치장 색, 문신, 문신 색, 점 및 흉터 등, 체격, 키, 가슴둘레, 목소리 유형.
