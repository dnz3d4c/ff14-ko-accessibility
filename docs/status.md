## 3. W-01 — KR 설치기

**문제**: 플러그인을 손으로 빌드해 `devPlugins`에 풀고, `dalamudConfig.json`을 스크립트로 심고, vnavmesh를 따로 받아 또 심어야 한다. 절차가 [kr-runtime-setup.md](kr-runtime-setup.md) §3~§8에 걸쳐 8단계다.

**업스트림에는 이미 있다.** `Installer/` — WinForms 자체 포함 단일 EXE이고 스크린리더를 전제로 만들어졌다(표준 컨트롤 + 포커스 가능한 로그 텍스트박스 + MessageBox). Dalamud 자체 플러그인 창이 ImGui라 못 읽히기 때문에 나온 물건이라 우리 사정과 정확히 같다.

**그대로 못 쓰는 이유 넷.**

| 지점 | 업스트림 | KR |
|------|----------|-----|
| 프로필 루트 | `%APPDATA%\XIVLauncher` (`InstallerService.cs:44`) | `%APPDATA%\XIVLauncherKR` |
| 없을 때 대응 | XIVLauncher를 받아 설치 (`:122`) | KR엔 XIVLauncher가 없다. [kr-runtime-setup.md](kr-runtime-setup.md) §3~4의 부트스트랩 3종이 필요 |
| 플러그인 출처 | 업스트림 GitHub 릴리스 (`:33`) | 그 바이너리는 CS 7.55 바인딩이라 **KR에서 안 뜬다.** 우리 빌드여야 한다 |
| 안내 언어 | 독일어·영어 (`Loc.cs`) | 한국어 |

**결정**: 업스트림 설치기를 `overlay/patches/`로 KR화한다. 새로 짜지 않는다 — 자체 포함 EXE 구성, 자기 갱신, dalamudConfig 조작 순서가 이미 검증돼 있고 그게 이 물건의 어려운 부분 전부다.

**플러그인 출처는 로컬 빌드를 1순위로 한다.** 릴리스 채널은 아직 없고, 만드는 것은 외부 공개라 별도 판단이 필요하다(§7 D-1).

### 4-1. 모드 키와 게임 키 충돌 5건 (W-03)

모드가 스스로 감지해 로그에 찍는다. 2026-08-18 05:42:08 기준.

### 4-2. 독일어 키 이름 3건 (W-04)

`Strg+F`, `Umschalt+Pos1`, `Alt+Pos1`을 `KeyNames` 파서가 모른다. **바인딩 3개가 조용히 죽어 있다.** 업스트림 결함이고 KR 무관이라 `[상류]` 후보다.

### 4-3. vnavmesh 설정 파일 없음 (W-08)

기동마다 `pluginConfigs\vnavmesh.json` FileNotFound로 `[ERR]`이 하나 뜨고 기본값으로 진행한다. 동작에는 지장이 없지만 **이 로그의 유일한 `[ERR]`이라 다른 오류를 가린다.** `seeds-local.json`도 같다.

### 4-4. 타이틀 메뉴 항목 수 5/6 불일치 (W-09)

메뉴 전체 안내는 "1 of 5", 화살표 이동은 "1 of 6". 가시성 변경 전후 로그가 같으므로 회귀가 아니다. KR 무관 추정, 미조사.

## 8. 이 문서를 쓰는 법

**기능 구현·수정·개선을 시작할 때 여기를 먼저 연다.** 없는 일을 하지 않고, 하는 일에 ID를 붙인다.

- 새 일이 생기면 `W-NN`을 새로 딴다. **ID는 재사용하지 않는다.**
- 상태는 `대기` → `진행` → `완료`. 접는 것은 `보류`(막힌 것)와 `버림`(안 하기로 한 것)으로 구분한다.
- 완료한 항목은 §2 표에서 **지우고** §9에 한 줄로 옮긴다. 표가 길어지면 아무도 안 읽는다.
- §1 "지금"은 **덮어쓴다.** 이력을 쌓지 않는다 — 이력은 git log가 갖는다.
- 근거는 여기 쓰지 않는다. `docs/`의 해당 문서에 쓰고 여기서는 링크한다.

**커밋이 이 규칙을 강제한다.** `[상류]`·`[오버레이]`·`[검증]`·`[도구]` 커밋은 이 파일을 같이 건드리거나, 안 건드리는 이유를 트레일러로 밝혀야 한다. 검사기는 `tools/commit-lint`의 C8이다.

```
Status-Board: W-01 진행
```

```
Status-Board: 해당 없음 - 오타 수정
```
